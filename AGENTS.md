# AGENTS.md — WiiBrowser Lite

Wii homebrew browser (PowerPC750/GEKKO, libogc/GX). Cross-compiled with devkitPPC — never with host gcc except `make test`.

## Build / verify (needs `DEVKITPRO`/`DEVKITPPC`)

```sh
export DEVKITPRO=/opt/devkitpro DEVKITPPC=$DEVKITPRO/devkitPPC PATH=$DEVKITPRO/tools/bin:$PATH
make                  # -> boot.elf / boot.dol (objects in path-preserving build/)
make forwarder        # optional HBC forwarder -> forwarder/boot.dol
make test             # host-only unit tests (native g++, NOT devkitPPC); or make -C tests
make lint             # clang-tidy probe + clang-format --dry-run --Werror
make package          # HBC bundle -> dist/apps/{wiibrowser,wiibrowser-lite}/ + WiiBrowser-Lite-HBC.zip
make clean            # rm build/ + outputs; make distclean ALSO deletes generated css_lex/css_syntax + dist/
```

No devkitPPC? Use Docker (same as CI, `.github/workflows/main.yml`):
`docker run --rm -v $PWD:/src -w /src devkitpro/devkitppc:latest bash -lc "make -j$(nproc)"`.
`run`/`reload` targets use `wiiload` (needs real Wii/network) — don't run in CI/agents.

## What goes where

- Entry: `src/core/main.cpp` `main()` → `InitVideo/SetupPads/fatInit/InitGUIThreads/InitFreeType` → `Settings.Load()` → `MainMenu`. `src/ui/menu.cpp` is a God object — edit surgically.
- `src/{core,ui,media,filesystem,archive,network,html_parser,text,utils}/`, `external/{libwiigui,litehtml,mplayerwii}/`, `assets/{images,appbar,fonts,sounds,lang}/`, `HBC/`, `forwarder/`, `scripts/`, `tools/`, `tests/unit/`.
- `external/mplayer` is reduced to 2 vendored files (`README.md`, `osdep/gx_supp.h`) — the `.gitmodules` entry is stale (no gitlink in HEAD) — and disabled by default (`src/core/config.h` `#undef MPLAYER`). Don't `git submodule update --init` unless doing media work. Never delete `forwarder/data/app_booter.dol` (embedded via bin2s).
- Known globals debt: `Settings`, `history` (`src/core/common.h`), `curl_handle` (`src/ui/menu.cpp`), `vmode` — don't add new globals; `src/core/context.h` `AppContext` is the migration path.

## Gotchas (agent would guess wrong)

- Assets are embedded via `scripts/embeddata.sh` (not `bin2o`): defines `<name>`, `<name>_end`, `<name>_size`. Reference externs must match `basename` with `.`→`_` (e.g. `font_ttf_size`).
- CSS parser `src/html_parser/css_{lex,syntax}.c/.h` are **gitignored build outputs** regenerated by flex/bison from `.l`/`.y` (required — installed in Docker/CI). `make distclean` deletes them — `make clean` does not.
- Link quirks in `Makefile`: auto-selects `-lwolfssl` vs legacy `-lcyassl`; minizip links vendored `libs/wii/libzip.a` explicitly (NOT `-lzip` — portlibs `libzip` is ABI-incompatible); `libs/include` is a last-resort fallback after portlibs and is gitignored. Trust `Makefile`/`Dockerfile`/CI over `BUILD.md` prose if they conflict.
- Build is path-preserving (`build/src/...` mirrors); old `notdir` filename-collision bug is fixed, dup basenames only warn.
- `HBC/meta.xml.in` (`@VERSION@`/`@RELEASE_DATE@` via `scripts/gen_version.sh`) is canonical; `make package` dual-installs `wiibrowser` + `wiibrowser-lite`.
- Host tests live in `tests/unit/*.cpp` (doctest single-header, pure logic only: URL/stringop/archive). `tests/Makefile` builds `test_url_helper test_stringop test_freetype_guard`. Wii-only code (GX/libogc) cannot run on host — guard or stub it.

## Style / workflow

- C++17 (`gnu++17`), C17; 4-space, LF, 100-col, `SortIncludes` per `.clang-format`/`.editorconfig` (Makefiles use tabs). Run `clang-format -i <file>` before committing; hooks: `git config core.hooksPath .githooks` (also `.pre-commit-config.yaml`).
- No `sprintf`/`bzero` (use `snprintf`/`memset`), no `TODO` without issue link, no commented-out code, prefer `std::string`/RAII. Conventional commits (`feat:`, `fix:`, `chore:`); branch from `main`, PR to `main`; use `git mv` for renames (`git log --follow` history matters — see `MIGRATION.md`).
- Docs of record: `BUILD.md` (env/troubleshooting), `ARCHITECTURE.md` (dir map/entry), `MIGRATION.md` (`source/`→`src/` rename map), `docs/THIRD_PARTY.md` (enabling mplayer makes binary GPL; otherwise MIT).
